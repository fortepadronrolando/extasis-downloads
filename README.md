# Descargas de Extasis

Sistema de gestión para bares, cafeterías y negocios.

Este repositorio solo contiene los instaladores de **Extasis**. Se publican automáticamente en el release [`latest`](https://github.com/fortepadronrolando/extasis-downloads/releases/tag/latest) cada vez que se actualiza la aplicación.

| Plataforma | Descarga | Instalación |
|---|---|---|
| Windows | [extasis-windows.zip](https://github.com/fortepadronrolando/extasis-downloads/releases/download/latest/extasis-windows.zip) | Descomprimir y ejecutar `chefadmin.exe` |
| Android | [extasis-android.apk](https://github.com/fortepadronrolando/extasis-downloads/releases/download/latest/extasis-android.apk) | Abrir el APK y permitir la instalación de orígenes desconocidos |
| GNU/Linux | [extasis-linux.tar.gz](https://github.com/fortepadronrolando/extasis-downloads/releases/download/latest/extasis-linux.tar.gz) | Descomprimir y ejecutar `./install.sh` |

La aplicación comprueba al iniciarse si hay una versión nueva y muestra el aviso **Nueva versión disponible** en Inicio.
